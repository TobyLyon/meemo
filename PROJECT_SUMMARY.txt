🎪 ANIMATION SYSTEM
═══════════════════════════════════════════════════════════════════════════

The TumiWorld component automatically:
  1. Loads the GLB file from /public
  2. Extracts all animations
  3. Plays them in sync with infinite loop
  4. Logs animation names to console
  5. Provides debugger overlay (Ctrl+Shift+A)

Your walk and globe spin animations will play together seamlessly!

💡 TIPS & TRICKS
═══════════════════════════════════════════════════════════════════════════

1. If animations don't play:
   • Press Ctrl+Shift+A to see animation names
   • Check browser console for logs
   • Verify GLB file has embedded animations

2. For better performance:
   • Reduce Stars count in Scene.tsx
   • Disable post-processing effects
   • Lower shadow map sizes

3. To add more scroll sections:
   • Update scroll breakpoints in UI.tsx
   • Add new AnimatePresence blocks
   • Adjust camera path accordingly

4. For custom camera paths:
   • Use sine/cosine for smooth curves
   • Lerp camera position for smooth motion
   • Always lookAt the model center
