🔄 DATA FLOW
──────────────────────────────────────────────────────────────────────────

1. User scrolls page
   └─→ window.scrollY changes
       │
       ├─→ CameraController updates camera position
       │   └─→ 3D view rotates/zooms
       │
       ├─→ UI.tsx calculates activeSection
       │   └─→ Different content sections appear
       │
       └─→ BackgroundGradient shifts colors
           └─→ Background subtly changes

2. Page loads
   └─→ Suspense shows LoadingScreen
       └─→ GLB file loads from /public
           └─→ TumiWorld extracts animations
               └─→ All animations play in sync
                   └─→ Loading complete, show main page

3. Developer tools
   ├─→ Ctrl+Shift+P → Toggle PerformanceMonitor
   └─→ Ctrl+Shift+A → Toggle AnimationDebugger
